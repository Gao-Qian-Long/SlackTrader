# SlackTrader（蓝牙助手）

SlackTrader 是一款面向 Windows 的轻量桌面行情工具，提供 A 股报价、分时图、日 K、观察列表和本地持仓盈亏计算。应用采用紧凑浮窗设计，支持透明度与配色调整，并可在失去焦点后自动收回。

> 当前版本：**v0.4**

## 功能概览

- **紧凑浮窗**：微型模式集中显示标的名称、走势、现价和涨跌幅。
- **分时行情**：以昨收为中轴绘制对称涨跌幅坐标；报价与分时独立刷新。
- **日 K 图表**：红涨绿跌，支持 `Ctrl + 鼠标滚轮`缩放、拖动平移和双击复位。
- **观察列表**：可添加、切换、编辑和删除股票；支持部分行业板块数据适配。
- **持仓计算**：根据用户输入的数量与成本价，在本地计算当日盈亏、累计盈亏和收益率。
- **多源容错**：个股报价支持多个公开行情源依次回退，失败源会进入短时冷却。
- **状态可追溯**：设置中的“行情详情”可主动查看行情来源、源时间和错误信息。
- **低干扰交互**：窗口、控件和托盘不显示悬停提示；展开窗口失去焦点后自动收回。
- **外观定制**：背景、文字、涨跌、分时、均价和 K 线颜色以及整体透明度均可调整。
- **桌面集成**：支持托盘显示、全局快捷键、窗口位置记忆和多显示器边界修正。

## v0.4 变更

- 新增日 K 缩放、平移和双击复位操作。
- 日 K 使用红涨绿跌配色，并允许单独调整上涨、下跌颜色。
- 数据刷新期间保留用户当前的 K 线缩放范围。
- 日 K 区域的普通滚轮不再触发观察列表切换。
- 移除窗口、控件、图表轴标签和托盘的悬停提示；诊断信息改为点击后查看。
- 重构公开文档结构，使功能、隐私、使用和限制说明更清晰。

## 使用说明

### 管理观察列表

1. 展开窗口并打开设置。
2. 输入 6 位证券代码。
3. 如需计算持仓收益，同时填写数量和成本价；仅观察行情时可留空。
4. 点击“保存”。再次保存相同代码会更新原记录。

行业板块支持范围取决于当前版本内置的数据适配器。板块记录不参与持仓收益计算。

### 图表操作

| 操作 | 功能 |
| --- | --- |
| 点击“分时”或“日 K” | 切换图表类型 |
| `Ctrl + 鼠标滚轮`（日 K 区域） | 以指针位置为中心缩放 |
| 按住并拖动日 K | 水平平移 |
| 双击日 K | 恢复完整显示范围 |

### 窗口操作

| 操作 | 功能 |
| --- | --- |
| 微型窗口滚轮 | 切换观察标的 |
| 双击微型窗口 | 展开窗口 |
| 右键微型窗口 | 展开并打开设置 |
| 中键微型窗口 | 隐藏窗口 |
| `Esc` | 收回窗口 |
| `Alt + Shift + S` | 全局显示或隐藏 |
| 托盘图标左键 | 显示或隐藏 |

## 数据与隐私

- 观察列表、数量、成本价、主题和窗口位置保存在本机 WebView2 Local Storage 中。
- 应用不包含账户系统、云同步或遥测上报功能。
- 行情请求仅用于查询用户选择的证券或受支持板块；免费公开接口可能延迟、中断或调整字段。
- 异常时应用保留最后一次成功数据并明确标记状态，不生成模拟价格，也不以其他指数替代请求标的。

默认数据目录：

```text
%LOCALAPPDATA%\com.bluetoothassistant.desktop\EBWebView\Default\Local Storage
```

迁移数据前请先退出应用，再备份上述目录。常规覆盖安装不会删除该目录。

## 行情策略

- 交易时段内，报价与分时采用不同刷新周期，避免图表请求影响价格显示。
- 个股报价可在多个公开数据源之间回退；分时和日 K 使用各自支持的数据源。
- 对连续失败或返回 HTTP 429 的来源执行缓存、退避和 `Retry-After` 等待。
- 行情时间以数据源字段为准。客户端刷新频率不代表交易所级实时性。
- 交易状态当前依据北京时间、工作日及常规 A 股交易时段判断，未内置法定节假日交易日历。

## 已知限制

- 依赖第三方公开行情接口，其可用性和字段格式不由本项目控制。
- 行业板块目前只支持内置适配范围。
- 应用内交易日判断未覆盖临时休市和节假日调休。
- 便携版仍依赖系统 WebView2 Runtime。
