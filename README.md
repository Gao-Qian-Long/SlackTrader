# 蓝牙助手（Bluetooth Assistant）

一款面向 Windows 的轻量股票行情浮窗。支持 A 股实时价格、分时图、日 K、持仓盈亏和行业板块观察，界面紧凑、透明度与颜色可调，窗口失去焦点后会自动收回。

> 当前版本：**v0.3**

## 功能特点

- **微型行情条**：默认尺寸约 `232 × 28`，显示名称、走势、现价和涨跌幅。
- **分时与日 K**：分时图采用昨收居中、上下对称涨跌幅坐标；日 K 使用前复权数据。
- **持仓盈亏**：输入股票代码、持仓数量和成本价，显示今日盈亏、总盈亏和收益率。
- **板块观察**：输入 `881129` 查看同花顺原始“通信设备”板块报价、分时和日 K（含当日 K 线），无需填写数量与成本。
- **托盘信息**：鼠标悬停托盘图标可查看当前标的价格和盈亏信息。
- **自动收回**：展开窗口失去焦点或按下 `Esc` 后恢复为微型模式。
- **位置记忆**：记住微型窗口上次位置，并适配多显示器与工作区边缘。
- **个性化显示**：背景、文字、涨跌、分时线、均价线和透明度均可设置。
- **多源行情**：个股报价自动在腾讯、新浪、东方财富间切换；设置中可选择优先来源。分时及日 K 使用腾讯/东方财富主备。
- **独立刷新**：交易时段报价约 5 秒、分时约 30 秒；非交易时段分别约 60 秒、5 分钟。分时故障不再阻断价格和盈亏。失败源退避冷却，遇到 HTTP 429 尊重服务端 Retry-After，不循环轰炸接口。
- **真实数据状态**：不生成模拟价格；显示行情来源、源时间与错误原因，异常时明确标记最后成功报价。

## v0.3 更新

- 修复 `881129` 长期空白：直接接入同花顺 `bk_881129`，不再映射到东方财富 BK0448。
- 旧观察项自动迁移代码，保留原用户设置和持仓字段，无需删除重加。原东方财富指数与同花顺指数数值不同，升级后点位变化属于恢复正确口径。
- 板块报价采用原始行情时间；实时报价端点异常时，回退同代码的真实分时末笔，并标注来源。
- 同花顺分时/日 K 支持 v6、v4 端点回退（同一数据服务，并非两个独立来源）；当日 K 线单独获取并合并。
- 板块不绘制单位不同的每股均价，避免图表被错误压扁；不显示成交量。
- 个股来源优先级只对个股生效，选择板块时该下拉框禁用，避免误解。

## v0.2 更新

- 增加报价多源切换、分时/日 K 备用、短时请求缓存和限流退避。

## 安装

1. 在 GitHub 项目的 **Releases** 页面下载 `SlackTrader-v0.3-Setup-x64.exe`。
2. 双击安装包完成安装。
3. 升级时直接覆盖安装，应用会沿用原用户数据。

覆盖安装会保留股票列表、持仓数量、成本价、颜色、透明度、窗口位置和图表模式。升级时请保持应用标识 `com.bluetoothassistant.desktop` 不变。

## 使用方法

### 添加或修改股票

1. 展开窗口并进入设置。
2. 输入 6 位股票代码、持仓数量和成本价。
3. 点击“保存”。再次保存相同代码即可修改数量和成本。

### 添加板块

输入板块代码 `881129`，数量与成本留空，然后点击“保存”，即可查看通信设备板块行情。

### 操作方式

| 操作 | 功能 |
| --- | --- |
| 微型窗口滚轮 | 切换观察标的 |
| 双击微型窗口 | 展开窗口 |
| 右键微型窗口 | 展开并打开设置 |
| 中键微型窗口 | 隐藏窗口 |
| `Esc` | 收回窗口 |
| `Alt + Shift + S` | 全局显示或隐藏 |
| 托盘图标左键 | 显示或隐藏 |

## 用户数据

Windows 用户数据默认存放在：

```text
%LOCALAPPDATA%\com.bluetoothassistant.desktop\EBWebView\Default\Local Storage
```

覆盖安装不会替换该目录。需要迁移电脑时，可在应用退出后备份上述目录。

## 数据说明

- 个股报价来自腾讯、新浪或东方财富公开接口；分时和日 K 来自腾讯或东方财富。不同接口支持的代码范围不同。
- `881129` 报价、分时与日 K 均来自同花顺原始板块接口；整站故障时仍会明确提示待恢复，不切换为其他指数。
- 刷新间隔是客户端轮询频率，不代表行情零延迟；行情时间以服务端字段为准。交易时段按北京时间和工作日判断，尚未内置节假日日历。
- `881129` 对应[同花顺通信设备行业指数](https://q.10jqka.com.cn/thshy/detail/code/881129/)。v0.3 已移除旧版 `90.BK0448` 映射。
- 免费公开行情可能出现延迟、中断或字段调整，本项目展示最后成功获取的数据与时间。

## 常见问题

### 覆盖安装后数据是否保留？

保留。安装包继续使用相同应用标识和用户数据目录。不要先卸载并主动删除应用数据目录。

### 为什么窗口点击外部后变小？

这是默认交互逻辑，用于保持桌面整洁。再次双击微型窗口即可展开。

### 为什么行情暂时不更新？

v0.3 修复了通信设备板块单一来源空白，并接入同花顺原始代码。v0.2 修复了旧版“分时请求失败，连带报价和盈亏也不显示”的问题，并加入多源主备。

1. 个股可在设置中选择“自动（腾讯优先）”或其他优先级；881129 固定同花顺原始板块来源，个股优先级不适用。
2. 悬停状态栏查看具体来源、行情时间与错误：HTTP 429 是明确限流；连接失败或超时也可能由网络、服务端或接口变动引起，不一概归因于调用次数。
3. “分时待更新”不影响已成功的报价；“报价待恢复”表示当前显示的是最后成功数据。
4. 休市或停牌期间可能只有末笔成交；板块原数据源异常时不会借用另一板块冒充。

## 说明

本项目用于行情观察和持仓记录，显示结果不构成投资建议。交易前请以交易所及券商数据为准。
